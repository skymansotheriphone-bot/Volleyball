Sign in here on the device you use to control the score. The PRISM browser overlay connects automatically and receives live updates. Firebase Realtime Database must allow public reads and authenticated writes.

PRISM LIVE & BACKUP

In PRISM, add a Web Browser source using your GitHub Pages URL followed by ?overlay=1. The banner sits at the bottom-left by default; add &pos=center or &pos=right to move it. Match data syncs through Firebase when the controller is signed in; local browser storage remains as a backup.

For troubleshooting, append &debug=1 to the overlay URL to see received play events. Remove it before streaming.
